Upload a VM image from your machine, or register a link to one, so it can be catalogued before being turned into a Proxmox template. A pasted link is downloaded and stored the same way a chosen file is. {% if unchecked %}{{ unchecked }} not yet checked.{% endif %}

All uploads require appropriate quarantine and sanitisation checks as this system does not have any in place currently. Pasting a link also makes this server fetch that address itself, which is a server-side request forgery risk — only paste links you trust, and note that private and internal addresses are refused.
